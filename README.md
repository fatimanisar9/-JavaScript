## Callback

A callback is a function passed as an argument to another function.

## Promise

A Promise represents a value that may be available now, later, or never.

It has three states:

* Pending
* Fulfilled
* Rejected

## Async / Await

`async` and `await` are used to work with Promises in an easier and more readable way.
